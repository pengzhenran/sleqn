海平面指纹（SLF）计算程序 —— 安装完成
================================================================================

程序已经装好了。下面三件事建议先做一遍：

1. 先跑一次自检
   打开命令提示符（Win+R 输入 cmd 回车），执行：

       "C:\Program Files\海平面指纹\sleqn.exe" --selftest

   （如果你改过安装位置，把路径换成实际安装目录）
   它会检查随包文件、离线底图、数值内核与出图是否正常，最后打印
   "结论：20/20 项通过" 就说明这台机器上一切就绪。退出码 0 表示全部通过。

2. 用示例数据走一遍流程
   打开程序 → 左下角「载入演示数据（grace_example）」→ 点「▶ 开始计算」。
   示例是真实的 CSR GRACE/GRACE-FO RL06.3 mascon 数据（1° 网格、64800 个格点），
   普通笔记本上十几秒算完。算完自动切到「海平面指纹图」页签。

   本版本（v1.0.1）修掉了 v1.0.0 的一个缺陷：程序装在默认的
   "C:\Program Files\海平面指纹\" 下时，控制文件里的路径会被空格截断，
   一点「开始计算」就报 No such file or directory: 'C:\Program'。
   现在自检里多了一项「路径含空格的算例」，跑通即说明这个问题已修复。

3. 看使用说明
   程序里按 F1，或菜单「帮助 → 使用说明」。
   也可以直接打开安装目录下 _internal\docs\使用说明.html（浏览器版排版最完整）。


几个要点
--------------------------------------------------------------------------------
* 程序**完全离线**运行，不联网、不上传任何数据。
* 用自己的数据时，注意三件事（说明书第 4、6 节有详细说明）：
    - 质量变化数据的单位是**米**当量水高（GRACE mascon 原始产品是厘米，要除以 100）；
    - dlon / dlat 必须与数据的实际网格间隔一致；
    - 「允许负值载荷」必须勾选（GRACE 的质量亏损是负值）。
* 定量分析（趋势、区域平均）时把迭代次数 niter 设到 10 以上，
  默认的 2 与完全收敛解相差约 1%。


如果程序双击打不开（被 Windows 拦住）
--------------------------------------------------------------------------------
本程序没有购买商业代码签名证书，程序文件是「未签名」的。新装的 Windows 11 上
可能被系统安全功能拦下，按提示分两种：

A. 蓝色对话框「Windows 已保护你的电脑」/「未知发布者」
   → 点「更多信息」→「仍要运行」即可。

B. 「智能应用控制已阻止可能不安全的应用：……因为无法验证其发布者，
   无法确认它是否能安全运行」
   → 这是 Windows 11 的「智能应用控制」（Smart App Control）。它没有「放行单个
     程序」的白名单，只能把这项功能关掉：

        1) 打开「设置 → 隐私和安全性 → Windows 安全中心 →
           应用和浏览器控制 → 智能应用控制」；
        2) 开关选「关闭」，弹出「用户账户控制」时点「是」；
        3) 重新双击本程序，不需要重装。

   关掉后较新的 Windows 11 可以在同一页面重新打开，不必重装系统；也不会影响
   Windows 自带的病毒防护、不影响其它软件。

   注意：换安装目录（装到 D 盘、用户目录）没有用——它不看路径，只看程序有没有
   可信的数字签名。若这台电脑由单位/学校统一管理，开关可能被策略置灰改不了，
   这种情况请联系本机管理员。
